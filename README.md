# Forguncy 자동 견적서 생성 데모

Forguncy(노코드 플랫폼)로 구현한 **자동 견적서 생성** 데모입니다.
품목·수량·단가 등 정보를 입력하면 견적서를 자동으로 생성해주는 업무를 노코드로 구축한 예시를 확인할 수 있습니다.

> ⚠️ 본 데모는 예제용으로, 실제 견적서가 발행되지는 않습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/autoquotation)

## 📋 주요 기능

- 품목·수량·단가 입력
- 입력 데이터 기반 견적서 자동 생성
- 견적서 미리보기 및 인쇄/PDF 출력
- 견적 이력 조회

## 💾 Forguncy 다운로드

이 데모는 MESCIUS Forguncy로 제작되었습니다. 직접 열어보거나 커스터마이징하려면 아래에서 Forguncy를 다운로드하세요.

👉 [Forguncy 다운로드](https://www.mescius.co.kr/forguncy/download)

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 보고서 기능을 활용하면 견적서·발주서 같은 반복 출력 문서도 코딩 없이 자동화할 수 있습니다.
